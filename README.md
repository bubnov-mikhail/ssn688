# SSN-688(I) Hunter/Killer

Современный симулятор подводной лодки в духе **688(I) Hunter/Killer**, написанный на **Go** с использованием [Ebiten](https://ebitengine.org/) для графики и звука.

## Запуск

```bash
go run .
```

Сборка:

```bash
go build -o ssn688 .
```

Работает на **macOS**, **Linux** и **Windows**.

## Управление

### Главное меню
- `↑` / `↓` — выбор пункта
- `Enter` — подтвердить

### В игре
| Клавиша | Действие |
|---------|----------|
| `F1` | Пассивный сонар |
| `F2` | Активный сонар |
| `F3` | Анализатор спектра |
| `F4` | Картотека «подчерков» |
| `F5` | Пуск торпед (Fire Control) |
| `F6` | Маневрирование |
| `M` | Тактическая карта |
| `Space` | Пауза |
| `+` / `-` | Ускорение / замедление времени |
| `Ctrl+S` | Быстрое сохранение |
| `Esc` | Меню / снять паузу |

### Пассивный сонар
- `P` — вкл/выкл

### Активный сонар
- `A` — вкл/выкл
- `F` — передать импульс

### Спектр
- `←` / `→` — выбор пеленга

### Fire Control (688-style)
- `1-4` — выбор торпедного аппарата
- `O` — открыть наружный люк
- `C` — закрыть люк
- `G` — угол гироскопа
- `D` — глубина хода торпеды
- `S` — скорость (LOW/HIGH)
- `H` — включить самонаведение
- `Enter` — пуск
- `W` — обрыв провода

### Маневрирование
- `↑` / `↓` — скорость
- `Q` / `E` — курс
- `PgUp` / `PgDn` — глубина

## Сценарий

Подлодка игрока уже в море. Необходимо обнаружить и уничтожить:
1. Надводный боевой корабль противника
2. Подводную лодку противника

Противник ведёт активный поиск и может атаковать.

## Сохранения

Файлы сохранений — **простой текст** (`.sav`) в:
`~/Library/Application Support/ssn688/saves/` (macOS)

Содержат все объекты сцены, параметры оружия, контакты сонара и игровое время.

## Архитектура

```
internal/
  acoustics/   — гидроакустика, пассивный/активный сонар, спектр
  ai/          — поведение противника
  audio/       — реплики офицеров (разные тона по отсекам)
  config/      — настройки
  render/      — отрисовка
  save/        — текстовые сохранения
  sim/         — игровой движок
  weapons/     — торпеды и пуск
  world/       — объекты, сценарий, картотека шумов
  ui/          — меню и экраны
```

## Голоса офицеров

32 предзаписанных реплики встроены в игру (WAV → PCM). Озвучка через локальный нейро-TTS **Kokoro** (`mlx-audio` на Apple Silicon):

| Отсек | Голос Kokoro | Примеры |
|-------|--------------|---------|
| CAPT | `bm_george` (британский мужской) | «Rig ship for silent running…» |
| SONAR | `af_bella` | «Passive sonar online» |
| WEPS | `am_michael` | «Torpedo away, tube 3» |
| DIVE | `am_fenrir` | «Make depth, aye» |
| NAV | `bf_emma` | «Time acceleration double» |

Субтитры показывают точные значения (курс, глубина, угол гиро), когда в аудио — общая фраза.

Перегенерировать голоса (нужен `.venv-tts`, см. `scripts/generate_voices.sh`):

```bash
./scripts/generate_voices.sh
```
